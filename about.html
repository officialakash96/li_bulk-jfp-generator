About This Application

Purpose

This tool helps generate bulk JSON objects in the ManipulateValueConditionalOverwrite format. It eliminates manual JSON construction by allowing you to paste multiple value/compareValue pairs and automatically generating properly formatted JSON output.

How It Works

  1. Paste bulk data — Enter multiple rows of value and compareValue pairs (tab or comma separated, like copying from Excel).
  2. Set common parameters — Select or enter values for rank, field, compareField, sourceId, and fuzzyMatch. These are duplicated across all rows.
  3. Generate — Click "Generate JSON" to produce the output array with constant values for typeName, active, dynamic, and simulatorOnly.

Output Format

[
  {
    "typeName": "ManipulateValueConditionalOverwrite",
    "active": true,
    "rank": <numeric>,
    "dynamic": true,
    "simulatorOnly": false,
    "parameters": {
      "compareValue": "<user-input>",
      "field": "<dropdown-value>",
      "compareField": "<dropdown-value>",
      "value": "<user-input>",
      "fuzzyMatch": false
    },
    "sourceId": <numeric>
  }
]
