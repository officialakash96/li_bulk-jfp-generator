About This Application

Purpose

This tool generates bulk Job Field Processor (JFP) JSON objects for various typeName operations. It eliminates manual JSON construction by allowing you to paste multiple values and automatically generating properly formatted output.

Pages

  • Bulk Overwrite JFPs — Generate ConditionalOverwrite, ConditionalReplace, ValueReplace, and ReplaceEmpty JFPs
  • Bulk Ignore JFPs — Generate IgnoreContains, IgnoreEquals, IgnoreNotContains, IgnoreNotEquals, IgnoreEmpty, and IgnoreNotEmpty JFPs

Bulk Overwrite JFPs — Tabs

  1. Conditional Overwrite/Replace — ManipulateValueConditionalOverwrite or ManipulateValueConditionalReplace. Bulk paste value, compareValue, and optionally search.
  2. ManipulateValueReplace — Bulk paste search and value pairs. fuzzyMatch is always false.
  3. ManipulateValueReplaceEmpty — Bulk paste value only. Output parameters contain just field and value.

Bulk Ignore JFPs — Tabs

  1. IgnoreContains / IgnoreEquals / IgnoreNotContains / IgnoreNotEquals — Bulk paste values with field and ignoreCase selection.
  2. IgnoreEmpty / IgnoreNotEmpty — No value input needed. Select field and optionally rankAbove.

Special Handling

  • When field or compareField is set to company, values are formatted as urn:li:company:<input>
  • In ManipulateValueReplace, both search and value get the urn:li:company: prefix when field is company
  • All other fields (including companyName) use the raw input as-is
